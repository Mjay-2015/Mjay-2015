### Hi, I'm Natalie Donga.

I train and evaluate AI models, and I build products with them. My evaluation work covers supervised fine-tuning demonstrations, RLHF preference data, rubric design, safety and refusals, and review of model-written code. I also run [Mindcraft Foundry](https://mindcraftfoundry.co.za), a studio that adapts books for the screen with AI tools, where people sign off on every stage.

I design, specify and test everything below. Much of the code is written with Claude Code, and I review every change.
